## 1. 概述

**文件**: `src/backend/NativeBackend.cpp`（第 8-190 行）

7 个静态函数，纯 C++ `std::string` 实现，零外部依赖。

| 函数 | 算法 | 复杂度 | 说明 |
|------|------|--------|------|
| `bignorm(s)` | 去前导零 | O(n) | 工具，所有运算结束后调用 |
| `bignumAdd(a, b)` | 竖式逐位 | O(n) | 同号绝对值加，异号绝对值减 |
| `bignumSub(a, b)` | a - b = a + (-b) | O(n) | 调 bignumAdd |
| `bignumMul(a, b)` | 小学/Karatsuba | O(n^1.585) | < 80位小学，>=80位 Karatsuba |
| `bignumDiv(a, b)` | 长除法 | O(n²) | 逐位试除 |
| `bignumMod(a, b)` | a - (a/b)*b | O(n²) | 调 div + sub + mul |
| `bignumCmp(a, b)` | 符号→位数→逐位 | O(n) | 返回 -1/0/1 |
| `bignumPow(a, exp)` | 快速幂 + 10^n特化 | O(log e) | 负指数→0 (整数语义) |

**与 zcc_runtime.c 的关系**: 算法同源但独立实现（不依赖 C 运行时库的 BigNum 结构体）。

## 2. 数据表示

```
BigNum = std::string
         ├── 纯数字字符 '0'-'9'
         ├── 可选前导 '-'
         └── 最高位在前 (MSB first, 无翻转)
```

**bignorm() 规范化**:
```cpp
"000123"  → "123"
"-000"    → "0"
"+123"    → "123"
```

**负数处理**: 所有运算通过符号提取 → 绝对值计算 → 符号还原三步。

## 3. 加法 (竖式逐位)

```
  12345
+   678
───────
  13023
```

**算法**:
```
1. 末位对齐
2. 逐位相加 + 进位
3. 同号: |a| + |b|
4. 异号: |larger| - |smaller|, 保较大者的符号
```

**同号示例** (123 + 456 = 579):
```
  1 2 3
+ 4 5 6
───────
  5 7 9
```

**异号示例** (-5 + 3 = -2):
```
  5 (larger, 负号)
- 3 (smaller)
───
  2
符号: 保 larger 的符号 → -2
```

## 4. 乘法 (小学竖式 + Karatsuba)

### 4.1 小学竖式 (阈值 < 80 位)

```
    123
×   456
───────
    738   (123 × 6)
   615    (123 × 5, 左移1位)
  492     (123 × 4, 左移2位)
───────
  56088
```

**实现**: 双重循环 O(n×m)，结果存入 `vector<int>` 逐位累加。

### 4.2 Karatsuba (阈值 >= 80 位)

```
x = a1 * B^m + a0
y = b1 * B^m + b0

z2 = a1 * b1                    (递归)
z0 = a0 * b0                    (递归)
z1 = (a1+a0)*(b1+b0) - z2 - z0  (递归)

result = z2 * B^(2m) + z1 * B^m + z0
```

3 次递归乘法替代小学的 4 次。B = 10。

**复杂度**: 从 O(n²) → O(n^log₂3) ≈ O(n^1.585)。

**阈值选择 (80 位)**: 小学数学在 80 位以下更快（常数因子小），Karatsuba 在大数上开始显现优势。80 是实验平衡点。

## 5. 除法 (长除法)

```
56088 ÷ 456 = ?

第1步: 5 < 456 → Q=0, 继续
第2步: 56 < 456 → Q=0, 继续
第3步: 560 ≥ 456 → Q=1, cur=560-456=104
第4步: 1048 ≥ 456 → Q=2, cur=1048-456*2=136
第5步: 1368 ≥ 456 → Q=3, cur=1368-456*3=0
结果: 123
```

**实现要点**: 逐位扩展被除数 → 当 `cur >= divisor` 时试除计数 → 减去除数 → 构建商。

**复杂度**: O(n²)。长除法是 BigNum 中最慢的运算，10^n 特化路径可大幅缓解。

## 6. 快速幂

```
a^e, e 为正整数

if e == 0: return "1"
if e < 0:  return "0" (BigNum 整数语义)

10^n 特化:  return "1" + n个"0"

通用二分快速幂:
  r = "1", base = a
  while e > 0:
    if e & 1: r = r * base
    base = base * base
    e >>= 1
  return r
```

**示例**: 2^16 只需 5 次乘法（log₂16=4，含初始化）

## 7. 10^n 特化路径

幂、乘、除都检测 10^n 模式，走 O(1) 路径：

```
isPow10("1000") → 3    ("1" + 3个"0" → 10^3)
isPow10("500")  → -1   (不是10的幂)

10^pa * 10^pb = 10^(pa+pb)  → "1" + (pa+pb)个"0"
10^pa / 10^pb = 10^(pa-pb)  → "1" + (pa-pb)个"0"
10^50000       → "1" + 50000个"0"  (瞬时)
```

## 8. 性能边界

| 运算 | 算法 | 10^6 级 | 10^9 级 |
|------|------|---------|---------|
| ADD/SUB | 逐位 O(n) | ✅ 可行 | ⚠️ 较慢但可行 |
| MUL (通用) | Karatsuba O(n^1.585) | ✅ | ⚠️ |
| MUL (10^n) | 特化 O(1) | ✅ | ✅ |
| DIV (通用) | 长除 O(n²) | ⚠️ 慢 | ❌ 极慢 |
| DIV (10^n) | 特化 O(1) | ✅ | ✅ |
| POW | 快速幂 O(log e) + 10^n特化 | ✅ | ✅ |

**结论**:
- **10^n 运算**: 瞬时（特化路径）
- **通用乘除法**: Karatsuba 对大数有效改善，但长除法仍是瓶颈
- **10^50000**: 10^n 特化覆盖 → 全部 O(1)
- **提高通用除法性能**: 需要 Newton-Raphson 除法或 Barrett reduction（远期优化）
